# Mini Concept Index

This document provides lightweight conceptual entry points
for recurrent terms used throughout the 12P framework.

The purpose of this layer is not to provide exhaustive definitions,
but to support:

* fast semantic re-entry
* lightweight conceptual navigation
* reduced reconstruction cost
* terminology stabilization across layers

This index functions as a lightweight navigation layer
between:

* README-level orientation
* core conceptual definitions
* terminology mapping structures
* manuscript-level theoretical discussion

The focus is placed on:

* conceptual accessibility
* topology readability
* semantic continuity
* cross-document coherence

rather than complete theoretical explanation.

Related supporting layers include:

* `core-definitions.md`
* `terminology-table.md`
* manuscript-layer terminology sections

This layer is intended to support:

* lightweight instances
* future reconstruction
* cross-session continuity
* topology-aware semantic navigation

without introducing unnecessary terminology inflation.
