# Observation Asset Placement Guide (ASCII Representation)

## Purpose

This note provides a compact operational representation of the current placement workflow used within the research space.

The purpose is not to establish a theoretical classification system.

The purpose is to support consistent placement decisions for newly created observation assets.

## Interpretation

The diagram illustrates the current operational logic used when determining the placement of new observation assets.

The primary organizing question is:

> What is being observed?

Rather than classifying assets by superficial similarity, placement decisions are guided by the primary observation object.

Observed categories currently include:

* Structure
* Research Questions
* Observation Processes
* Research Program Evolution

Different observation types may therefore be directed toward different sections of the repository structure.

---

## Relationship to Placement Principle

This diagram represents an operational application of the Placement Principle.

The Placement Principle emerged from repeated placement difficulties and classification ambiguities.

The present diagram illustrates how that principle is currently applied during day-to-day repository operations.
