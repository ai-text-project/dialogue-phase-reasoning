# Externalization Observation Criteria（Draft v1）

## Status

本ドキュメントは、Dialogue-Phase Reasoning 研究プログラムにおける
Structure-Preserving Externalization（Stage 3）に関する、
暫定的な観測フレームワークである。

本ドキュメントは、
Externalization を最終定義するものではなく、

* projection
* density transformation
* low-loss externalization
* external shell formation
* public structural organization

などに関する Case 比較のための観測項目を整理することを目的とする。

---

# 研究方向性

現時点での研究方向は：

> Externalization を理論的に先に固定するのではなく、
> Case比較を通じて、
> 「どのような条件で意味構造が低損失で外殻へ投影されるか」
> を観測的に整理する

というアプローチを採用している。

つまり：

Case observation
↓
projection comparison
↓
stabilization pattern extraction
↓
externalization condition analysis
↓
tentative definition refinement

という順序を重視する。

---

# 暫定的作業定義

暫定的には：

> Externalization とは、
> 対話を通じて整流・保持された意味構造が、
> 異なる外部形式へ投影された後も、
> 意味骨格を大きく崩さず保持する過程

として整理される。

ただしこの定義は、
今後の Case 比較によって継続的に修正されうる。

---

# 提案される観測項目

以下は、
Externalization 観測のための軽量比較項目である。

これらは binary condition ではなく、
比較用の観測軸として扱う。

---

## 1. Projection Fidelity（射影忠実性）

観測対象：

* 外殻化後も意味骨格が保持されるか

観測例：

* semantic skeleton preservation
* topology continuity
* structural coherence after projection

---

## 2. Density Transformation Stability（密度変換安定性）

観測対象：

* 高密度構造を軽量形式へ変換しても芯が残るか

観測例：

* Detailed → Simple
* AI Textbook → Medium / Mini
* dense memo → README

---

## 3. Cross-Format Coherence（形式横断整合性）

観測対象：

* 異なる外部形式間で構造的一貫性が維持されるか

観測例：

* figure ↔ README
* GitHub ↔ paper
* Medium ↔ AI Textbook

---

## 4. Structure-Preserving Topology（構造保持型Topology）

観測対象：

* repository / folder / README 構造が意味構造を保持しているか

観測例：

* stage-aligned hierarchy
* repository topology stabilization
* governance-consistent organization

---

## 5. Lightweight Externalization（軽量外殻化）

観測対象：

* 過剰生成や topology inflation を起こさず外殻化できるか

観測例：

* anti-expansion behavior
* minimal README stabilization
* lightweight hub organization

---

## 6. Public Readability（外部可読性）

観測対象：

* 外部向け形式に変換しても可読性を維持できるか

観測例：

* simplified explanation
* reduced semantic overload
* bridge-layer accessibility

---

## 7. Recursive Reusability（再帰的再利用性）

観測対象：

* 外殻化後の構造が再び別形式へ投影可能か

観測例：

* GitHub → Medium
* README → Figure
* Bridge → Mini Paper

---

# 暫定的評価方法

現段階では、
軽量比較モデルが適切と考えられる。

例：

| Score | Meaning             |
| ----- | ------------------- |
| 0     | 観測なし                |
| 1     | 弱く観測                |
| 2     | 明確に観測               |
| 3     | repeatedly observed |

このスコアリングは、
Case比較のための仮設的観測補助として用いる。

---

# 推奨比較軸

比較候補：

* lightweight projection vs topology inflation
* README-centered vs content-centered organization
* projection-oriented vs migration-oriented handling
* stabilized structure vs unstable structure
* governance-constrained vs unconstrained externalization
* repository topology aligned vs misaligned

これらの比較により、
Externalization を支える条件の抽出を試みる。

---

# 重要な方法論的原則

現在の研究では：

> 「どれだけ生成したか」

より、

> 「どれだけ崩さず外へ出せたか」

を重視する。

したがって、
主観測対象は：

* semantic preservation
* low-loss projection
* structural continuity
* external shell coherence

である。

---

# 暫定的位置づけ

現時点で Externalization は：

* 完成理論
* 固定的定義

ではなく、

* projection-oriented observational category
* structure-preserving transformation hypothesis
* semantic externalization phenomenon

として扱われる。

---

# Open Questions

現時点で未解決な論点：

* どこまで保持されれば low-loss と言えるか
* projection fidelity はどう比較可能か
* stabilization は externalization 前提か
* externalization 自体が stabilization を強化するか
* topology は projection fidelity にどの程度影響するか
* lightweight externalization は再現可能か
* README-layer architecture は externalization support condition か

これらは今後の継続的研究課題である。
