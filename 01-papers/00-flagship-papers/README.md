# Flagship Papers Layer

This layer organizes the primary papers
within the Dialogue-Phase Reasoning research program.

The flagship-paper structure is divided into:

- Core Papers
- Extended Papers

The purpose of this layer is to provide:

- conceptual entry points
- structural orientation
- research navigation pathways
- semantic connections across the repository

---

## Core Papers

The core papers function as the primary structural foundations of the research program.

Focus areas include:

- dialogue-phase emergence
- structural jumps
- resonance organization
- semantic state-space dynamics
- long-duration semantic interaction

→ `01-core/`
