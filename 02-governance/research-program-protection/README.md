# Research Program Protection

## Purpose

To preserve the integrity, continuity, and independence of the core research program while allowing multiple external-facing initiatives to develop in parallel.

---

## Scope

This directory contains governance documents related to the protection of the research program from unintended external influence.

The purpose is not to restrict exploration.

Rather, it is to preserve the independence of:

- Research Program
- Research Mapping
- Case Structure
- Observation Framework

while allowing external-facing activities to develop.
